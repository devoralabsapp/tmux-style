# Logo assets

`tmux-style.svg` is the original editable artwork. `tmux-style.png` is the 512 px documentation rendering. `windows-terminal/tmux-style.ico` contains 16, 24, 32, 48, 64, 128 and 256 px variants for Windows resources.
